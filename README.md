# Plezix Browser

![Plezix Browser](./docs/readme/readme-banner.svg)

**Plezix Browser** is an independent web browser built on Mozilla's Firefox and Gecko codebase. This repository contains the browser source, platform integrations, and build configuration for the Plezix product.

Plezix keeps the strengths of the open web platform while presenting them under its own product identity.

## Building

Plezix uses the Mozilla build system. Start with the [Firefox Source Docs](https://firefox-source-docs.mozilla.org/) for platform prerequisites, build instructions, and troubleshooting.

## Contributing

For Plezix-specific bugs and product requests, use the [GitHub issue tracker](https://github.com/Vladprohxjx/plezix/issues).

Changes intended for upstream Gecko or Firefox should follow the [Mozilla contribution guide](https://firefox-source-docs.mozilla.org/contributing/contribution_quickref.html) and use the appropriate upstream issue tracker.
